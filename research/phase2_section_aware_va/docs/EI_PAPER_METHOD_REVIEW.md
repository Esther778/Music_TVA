# EI Paper Method Review And Writing Notes

Created: 2026-06-16

Scope update (2026-07-21): the current EI paper no longer includes an AIGC
comparison. References to human/AIGC comparison below are retained only as the
historical design review. The active paper scope is section-aware emotion
structure analysis of human-created Chinese popular music, with direct blind
section-level human validation.

## Current Research Design

The current project is a two-stage music emotion modeling study.

Stage 1 trains a frame-level Valence-Arousal predictor on DEAM. The current
MERT-based retraining compares MLP, BiLSTM, and Transformer heads. The best
current candidate is:

```text
feature_backbone=m-a-p/MERT-v1-95M
va_head=bilstm_baseline
val_rmse=0.219934
test_rmse=0.202452
test_pearson_valence=0.511522
test_pearson_arousal=0.641069
```

Stage 2 applies the selected Stage 1 predictor to reviewed full songs, then
aligns the model-derived frame-level VA curves with human-reviewed section
boundaries and section types. The goal is to model complete-song emotional
structure and compare human music and AIGC music in emotional progression,
climax organization, and section contrast.

## Professional Verdict

This can become a qualified EI-level paper, but not if it is written simply as
"we trained a better VA predictor and then trained another model on its
outputs." The strongest publishable angle is:

```text
A section-aware complete-song emotion-structure modeling framework that uses a
DEAM-trained frame-level VA predictor as a teacher model, then analyzes how
section boundaries and section types organize emotional progression in human
and AIGC music.
```

The paper should be positioned as a music information retrieval and music
emotion structure analysis paper, not as a pure emotion-recognition accuracy
paper. The Stage 2 labels are pseudo labels generated by Stage 1, so Stage 2
cannot be claimed as learning ground-truth human emotion unless additional
human VA annotations are collected.

## Core Weaknesses

### 1. Stage 2 Uses Pseudo VA Labels

The full-song VA curves are generated by the Stage 1 model. They are not
human-annotated VA ground truth.

Risk:

- If Stage 2 is evaluated against the same Stage 1-generated VA values, the
  result only proves that Stage 2 can imitate the teacher model.
- It does not prove that Stage 2 is closer to real human emotional perception.

Required fix:

- Use terms such as `model-derived VA`, `pseudo-VA labels`, or
  `teacher-generated VA trajectories`.
- Make Stage 2's primary claim structural: emotional progression, contrast,
  climax organization, section-level dynamics.
- Do not claim that Stage 2 improves true VA recognition accuracy unless there
  is independent human VA annotation.

### 2. Domain Gap Between DEAM And Full Songs

DEAM contains many excerpts, while the target analysis is complete songs.

Risk:

- A model trained on short excerpts may not fully capture long-range emotional
  development in complete songs.
- Absolute VA values may be biased when applied to full-song audio.

Required fix:

- Focus Stage 2 on relative and structural features rather than only absolute
  VA values.
- Use features such as section-to-section delta, climax location, peak
  intensity, recovery after climax, repeated-section consistency, and contrast
  between verse/chorus/bridge.
- If possible, manually annotate a small calibration subset of full songs for
  coarse VA or climax positions to validate the direction of the model-derived
  curves.

### 3. Current Stage 1 Model Still Shows Overfitting

The best current Stage 1 model has a large train-validation gap:

```text
train_rmse=0.051500
val_rmse=0.219934
test_rmse=0.202452
```

Risk:

- The model is usable, but the paper should not describe it as highly
  generalized based on one split.

Required fix:

- Re-run the best configuration with multiple random seeds.
- Report mean and standard deviation.
- Add CCC, MAE, and per-dimension RMSE for Valence and Arousal.
- Use validation metrics for model selection and reserve test metrics for final
  reporting only.

### 4. Old Phase 2 Documentation Still Mentions OpenL3 + MLP

Some Phase 2 documentation still describes OpenL3 + MLP as the required
predictor. This is outdated after the MERT + BiLSTM result.

Required fix:

- Update Phase 2 implementation and documentation so the frame-level VA
  generation path uses the selected MERT + BiLSTM model.
- Keep OpenL3 + MLP as a baseline comparison, not as the main path.

### 5. Human Music vs AIGC Music Needs A Clear Experimental Definition

The comparison is only publishable if the human/AIGC groups are clearly
defined and controlled.

Risk:

- If AIGC and human songs differ in genre, duration, language, or production
  style, the model may detect confounds rather than AIGC-specific structure.

Required fix:

- Record metadata: source type, genre/style, language, duration, tempo if
  available, and song source.
- Match or stratify the groups where possible.
- Report group counts and exclusion criteria.
- Avoid causal claims such as "AIGC music lacks emotion" unless supported by
  rigorous evidence.

## Recommended Improvements Before Writing

### Minimum Required For A Defensible EI Submission

1. Correct Stage 1 model selection:
   - select by validation RMSE,
   - report test metrics only after final selection.
2. Add metrics:
   - RMSE,
   - MAE,
   - CCC,
   - Pearson r,
   - separate Valence and Arousal metrics.
3. Add repeatability:
   - at least 3 random seeds for the selected Stage 1 model,
   - ideally 5 seeds if runtime allows.
4. Keep OpenL3 as a baseline:
   - compare old OpenL3 + MLP/BiLSTM/Transformer against MERT + BiLSTM on the
     same DEAM split if possible.
5. Define Stage 2 as section-aware structure modeling:
   - do not call pseudo labels human ground truth,
   - evaluate section-level structural features.
6. Build a human/AIGC comparison table:
   - number of songs,
   - duration distribution,
   - section count distribution,
   - section type distribution,
   - average climax position,
   - emotional contrast statistics.

### Stronger Version If Time Allows

Add a small human validation subset:

- Select 10-20 complete songs.
- Ask annotators to label coarse emotional curve or section-level emotion.
- Use this subset to check whether model-derived VA and section-level trends
  are directionally plausible.

This would greatly strengthen the paper because it partially breaks the
teacher-model circularity in Stage 2.

## Suggested Paper Contribution Claims

Use claims like:

1. A MERT-based frame-level VA prediction baseline is trained on DEAM and
   compared across MLP, BiLSTM, and Transformer prediction heads.
2. A section-aware full-song emotion-structure modeling pipeline is proposed by
   aligning model-derived VA trajectories with reviewed section boundaries and
   section types.
3. Section-level emotional progression features are designed to quantify
   climax organization, section contrast, and emotional transition patterns.
4. The framework is applied to compare human and AIGC music at the structural
   emotion level.

Avoid claims like:

- "The model predicts real human emotion for complete songs accurately" unless
  full-song human VA annotations exist.
- "The second-stage model improves emotion recognition accuracy" if the target
  labels are generated by the first-stage model.
- "AIGC music is emotionally inferior" unless the data and statistics strongly
  support that specific claim.

## Recommended Paper Structure

### 1. Introduction

Problem framing:

- Music emotion recognition often predicts frame-level or clip-level emotion.
- Complete songs have section-level emotional organization.
- Human and AIGC music may differ not only in local emotion, but in emotional
  progression and structural contrast.

Research gap:

- Existing VA prediction does not explicitly model verse/chorus/bridge-level
  organization.
- AIGC comparison needs structure-aware emotional descriptors.

Contributions:

- DEAM-trained MERT-based VA predictor.
- Section-aware full-song emotion structure model.
- Section-level emotional progression feature set.
- Human vs AIGC comparison.

### 2. Related Work

Recommended subsections:

- Music emotion recognition and VA modeling.
- Self-supervised audio/music representation learning.
- Structural segmentation and section-aware MIR.
- AIGC music analysis and evaluation.

### 3. Method

Suggested method flow:

```text
DEAM audio -> MERT features -> MLP/BiLSTM/Transformer VA heads
          -> select best Stage 1 model
reviewed full songs -> Stage 1 pseudo-VA curves
                    -> align with section boundaries/types
                    -> section-level feature extraction
                    -> section-aware structure modeling
                    -> human/AIGC comparison
```

Important wording:

- Stage 1 output for complete songs should be called `pseudo-VA trajectory` or
  `model-derived VA trajectory`.
- Section labels should be described as reviewed or human-verified if they
  came from the QC process.

### 4. Experiments

Stage 1 experiments:

- DEAM split rule.
- MERT feature extraction.
- MLP/BiLSTM/Transformer comparison.
- Metrics: RMSE, MAE, CCC, Pearson r.
- Multi-seed stability.

Stage 2 experiments:

- Reviewed full-song dataset description.
- Section type distribution.
- Section-aware model training and evaluation.
- Human vs AIGC statistical comparison.

### 5. Results And Discussion

Tables to include:

- Stage 1 model comparison.
- Stage 1 multi-seed stability.
- Reviewed song dataset statistics.
- Section-type emotion feature statistics.
- Human vs AIGC comparison.

Figures to include:

- Overall framework diagram.
- Example full-song VA curve with section boundaries.
- Average emotional progression curve for human vs AIGC songs.
- Climax position distribution.
- Section contrast distribution.

### 6. Limitations

Must be explicit:

- Stage 2 VA labels are pseudo labels.
- DEAM excerpts differ from complete-song targets.
- Reviewed full-song dataset size is currently small.
- Human/AIGC comparison may be affected by genre and production confounds.

### 7. Conclusion

Do not overclaim. Emphasize that the framework provides a section-aware
quantitative way to study complete-song emotional organization.

## Suggested Section-Level Features

For each section:

- duration,
- section type,
- normalized start and end position,
- mean Valence and Arousal,
- standard deviation of Valence and Arousal,
- entry and exit VA,
- VA delta from section start to end,
- linear slope of VA,
- peak Valence/Arousal and peak time,
- contrast with previous section,
- contrast with next section,
- distance to song-level emotional peak,
- whether the section contains the song-level climax.

For each song:

- global VA range,
- number of emotional peaks,
- climax position ratio,
- maximum section contrast,
- mean chorus lift compared with verse,
- post-climax recovery slope,
- repeated-section consistency,
- section-type transition matrix,
- emotional arc type.

## Evaluation Design For Stage 2

If no human VA labels are available:

- evaluate how well the section-aware model reconstructs teacher-generated VA,
- evaluate whether section-level features classify or distinguish human/AIGC
  groups,
- perform statistical tests on group-level structural features,
- visualize representative examples.

If a small human validation set is available:

- compare model-derived section means with human section-level labels,
- compare predicted climax position with human-perceived climax,
- report inter-annotator agreement if multiple annotators are used.

## Immediate Next Actions

1. Update Stage 1 aggregation rule from test-based selection to validation-based
   selection.
2. Add CCC, MAE, and per-dimension metrics.
3. Run multi-seed stability for `bilstm_baseline`.
4. Update Phase 2 code/docs from OpenL3 + MLP to MERT + BiLSTM.
5. Generate pseudo-VA curves for reviewed full songs.
6. Extract section-level emotional structure features.
7. Define human/AIGC groups and metadata controls.

## Bottom Line

The current design is viable for an EI paper if the paper is framed as
section-aware music emotion structure modeling. The biggest weakness is not the
two-stage design itself; it is the lack of independent ground-truth VA labels
for Stage 2. This can be handled by honest terminology, structural evaluation,
baseline comparison, multi-seed validation, and ideally a small human validation
subset.
